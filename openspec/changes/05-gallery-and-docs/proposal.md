# Interactive gallery and documentation

## Why

Developers should understand AudioBits by hearing and adjusting sounds, then copy examples that actually work with the documented library version.

## Prerequisites

Step 04 accepted for the full gallery; an early core release can use the smaller Step 02–03 demo.

## What Changes

- Build a polished, accessible three-sound gallery and Fumadocs documentation.
- Add validated recipe editing, accurate code comparisons, and current-value copy behavior.
- Integrate optional visualization components only where they serve the listening workflow.

## Capabilities

### New Capabilities

- `sound-discovery`: Developers should understand AudioBits by hearing and adjusting sounds, then copy examples that actually work with the documented library version.

### Modified Capabilities

None. This change adds a distinct capability; dependent behavior remains governed
by its earlier change and must be reconciled if implementation changes it.

## Impact

Primarily website/docs and curated examples, with narrow runtime fixes only when evidenced by integration. No account system, remote generation, full IDE, or requirement to complete ten sounds.
