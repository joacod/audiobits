# Dynamic sounds and core milestone

## Why

Procedural sound earns its value through useful variation and continuous control. Two contrasting experiences must validate the recipe model beyond a single chime.

## Prerequisites

Step 02 accepted, including working finite playback and resource ownership.

## What Changes

- Add bounded generated noise, seeded variation, parameter mappings, and sustained voices.
- Implement variable impact and continuous thruster through the same recipe/compiler boundary.
- Complete the three-sound Chromium core and evaluate readiness for a small optional release.

## Capabilities

### New Capabilities

- `dynamic-sound-controls`: Procedural sound earns its value through useful variation and continuous control. Two contrasting experiences must validate the recipe model beyond a single chime.

### Modified Capabilities

None. This change adds a distinct capability; dependent behavior remains governed
by its earlier change and must be reconciled if implementation changes it.

## Impact

Extends draft recipe v1 and runtime capabilities, adds two recipes and their demo controls, and updates tests/metadata. No general expression evaluator, 3D spatialization, sequencer, worklet, or caching.
