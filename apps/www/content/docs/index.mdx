AudioBits is unreleased. These pages describe version 0.0.0 from the local
workspace, not an npm release. Build the library before the site using
`pnpm build:lib`, or run `pnpm dev` from the repository root for the watch loop.
The site and vanilla example consume public package exports.

## Play a confirmation

Create the engine and definition without allocating browser audio. Call `play()`
directly from your button's click handler and report rejected promises to the user.
Retry a failed start with a fresh Play gesture.

```ts
import { createAudio } from "audiobits";
import { confirmation } from "audiobits/recipes";

const audio = createAudio();
const sound = audio.sound(confirmation);
let request = 0;
export async function play() {
  const token = ++request;
  await audio.start();
  if (token === request && !document.hidden) sound.play({ seed: 42 });
}
export function stop() {
  request++;
  audio.stopAll({ tails: "cut" });
}
function hide() {
  if (document.hidden) {
    stop();
    void audio.suspend().catch(console.error);
  }
}
document.addEventListener("visibilitychange", hide);
export async function dispose() {
  stop();
  document.removeEventListener("visibilitychange", hide);
  await audio.dispose();
}
```

Bind `play()` and `stop()` to your host controls. Call `dispose()` on navigation or
unmount. Returning from a hidden page requires a new Play action. The gallery
never plays on load, hover, or navigation.
