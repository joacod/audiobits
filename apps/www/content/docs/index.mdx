Local development uses the workspace package. Build the library before the site using
`pnpm build:lib`, or run `pnpm dev` from the repository root for the watch loop.
The site and vanilla example consume public package exports.

## Play a confirmation

Create the engine and definition without allocating browser audio. Call `play()`
directly from your button's click handler and report rejected promises to the user.
Retry a failed start with a fresh Play gesture.

```ts
import { createAudio } from "audiobits";
import { confirmation } from "audiobits/recipes";

const audio = createAudio();
const sound = audio.sound(confirmation);
export async function play() {
  await audio.start();
  sound.play();
}
```

Bind `play()` to your button click and surface failures with
`void play().catch(showError)`. For hiding, SPA navigation, suspension and disposal,
see [Production lifecycle](/docs/lifecycle). The gallery never plays on load.
